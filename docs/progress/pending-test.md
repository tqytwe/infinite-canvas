- 创建前两端对齐主平台收费参数：duration 必填且为 1–15 整数，resolution 必须是 480p、720p 或 1080p；非法参数不得占位、扣 Canvas 积分或向上游 POST。同时拒绝重复 JSON 字段、过深嵌套以及网关不支持的素材 URL；服务器回归覆盖非法请求零扣费、零占位和零 POST，仍待浏览器错误提示验收。

- 不确定提交必须人工对账，禁止生成新 ID 再扣款；主平台异步记账中断仍需人工核对。
